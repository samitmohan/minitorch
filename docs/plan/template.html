minitorch: the plan

The goal is to prove I can write every fundamental of a modern LLM stack myself, then wire it into one end-to-end system: from a BPE tokenizer and autograd, through Metal kernels and real Qwen3 weights, to a paged-KV inference server that a RAG app and an agent call. Six milestones, one per phase of the study plan. The diagram grows with each one, and green marks what that milestone adds.
